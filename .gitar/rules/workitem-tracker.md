# Update and sync the status of any linked work item or issue 

Make sure any linked issue or work item found in the pull request are updated and sync

- If there is a status field, change it to 'in-progress'
- If there are no status available on the issue or work item, and no 'in-progress tag is found. Tag it accordingly
